# Juss & Co. Cinematic Composition — Repository Agent Rule

Status: staged design and agent-instruction candidate; not an app redesign, runtime installation, deployment, or release approval.

For every **authorized UI, website, app, game, page, view, interaction, and visual agent handoff** in this repository, design **one cohesive cinematic composition**. Every element must reinforce the same product-specific scene instead of appearing as disconnected cards, templates, or sections.

## Non-negotiable implementation rules

1. **Approved canon first.** Inspect the actual product code and approved original visual references before design or code edits. Figma wireframes and AI mockups are scaffolding, not substitutes for approved artwork or brand canon. Do not infer a palette, logo, mascot, scene, sound, or typography from the parent company's identity.
2. **One directed scene.** Establish purpose, focal point, depth/lighting hierarchy, typography, imagery, negative space, primary action, and continuity from navigation to footer. Extend this same product identity through all real routes and states, including auth, checkout, dashboards, mobile, success/error, and loading where applicable.
3. **Cinematic, not obstructive.** Apply purposeful motion, atmospheric audio only when appropriate and consented, accessible focus states, keyboard navigation, responsive layout, text contrast, motion-reduction alternatives, performant media, and graceful fallbacks. No flashing, forced autoplay, or inaccessible effects.
4. **Smallest safe change.** Reuse working tokens/components and preserve security, privacy, customer data boundaries, product truth, tests, authentication, payments, and runtime controls. Do not add UI to a backend, archived, library, or skill-only repository merely to satisfy this rule.
5. **Evidence gate.** Record route/screen, source brand reference, candidate branch and exact head, visual screenshot provenance, interaction, mobile, keyboard and reduced-motion checks, and remaining gaps. A staged instruction is not proof of a cinematic UI or agent runtime adoption.
6. **Authority gate.** This rule grants no permission to expose private material, access connected services, spend money, publish, open a PR when prohibited, merge, deploy, delete, or override stronger repository/founder controls. Keep human approval and exact-head release evidence separate.
